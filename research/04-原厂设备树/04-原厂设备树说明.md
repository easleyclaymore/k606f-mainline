# 4. 原厂设备树（DTB / DTS）

> 对应清单第 4 项：原厂固件对应的 DTB，或已反编译的 DTS。这是核对 panel、DSI 时序、供电和 GPIO 最有价值的资料。

## 本包内文件

| 文件 | 大小 | 说明 |
|---|---|---|
| `fdt.dtb` | 686 KB | **原厂运行时 dtb 原件**（从设备上取下来的，未改动） |
| `fdt-clean.dts` | 1012 KB | 用 `dtc -I dtb -O dts` 从上面那个 dtb **正确反编译**出来的文本 |

## 怎么用

```sh
# 自己重新反编译（推荐，保证可信）
dtc -I dtb -O dts -o fdt-clean.dts fdt.dtb

# 反编译 board dtb（我们自己的板级树）
dtc -I dtb -O dts out/kernel-msmmod/arch/arm64/boot/dts/qcom/sm8250-lenovo-k606f.dtb
```

想看的关键节点：

| 要找什么 | 在 dts 里搜 |
|---|---|
| 显示面板节点 | `qcom,mdss_dsi_dual_sim_video`（这是本机实际活动的面板配置） |
| DSI 时序 | 面板节点里的 `qcom,mdss-dsi-panel-width/height`、`h-front-porch`、`h-back-porch`、`h-pulse-width`、`v-*` |
| 桥 / mux | `eDP-MUX@66`（这是 PS8331 mux，`0x66` 是 8-bit 写法 = 7-bit `0x33`） |
| 供电 | 桥节点的 `vcc` / `vcca` / `vpll` / `vccio` 等 supply 引用 |
| GPIO | 桥节点的 `enable-gpios`、`reset-gpios`、`mipi-to-edp-en` 等 |
| 触控 | `goodix,gt738x` @ `i2c@a94000`，addr `0x5d` |

## ⚠️ 重要警告：别用 `fdt.dts`

项目里/网上可能还能看到一个 `fdt.dts`，那是早期**自写 dumper** 生成的，**属性解析会错位**：

- 3 cell 的 GPIO 属性、`#size-cells` 等会被渲染成乱码字符串；
- 从它读出来的 **GPIO 编号 / 中断号 / cell 数都不可信**。

**一律以 `dtc -I dtb -O dts` 的产物（本包的 `fdt-clean.dts`）为准。**（技术债 #15）

## 不同 dtb 的分工（别混）

| dtb | 用途 |
|---|---|
| `fdt.dtb`（本包） | **原厂**运行时设备树，取证权威源：面板时序、供电、GPIO、桥节点 |
| `sm8250-lenovo-k606f.dtb`（包内 `02-构建信息/`） | **我们自己编译**的板级树，实际烧给内核用的那份 |
| 原厂 `dtbo`（未在本包） | Android 侧的 overlay，依赖上百个 vendor 符号；我们自洽的 DTB 叠不上去，所以上机前会 `fastboot erase dtbo_a` |
